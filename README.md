# Resident-Evil-Credit-FMV-Slicer
A tool for slicing from one image into saparate images, for Resident Evil Classic credit PlayStation 1 FMV.

Note you need first rip the staff files into .bmp or png so the program can read it, because this tool doesn't support for .STF files.

# Features

This tool includes:

- Remover background option.
- No Remover Backgroud so the backgrond of the original image will stays as it is with no quality loss.
- Cut off. (Currently there's no need to use it)

You can later use it to manaully convert it to video.

Don't expect at this moment:

- convert to STF, because currently I haven't found the way to mod the .stf files.
- Convert the FMV fully to a video, beacause staff.stf and ending.exe I haven't found a way to do so yet.


Tools that I used:

- [Tesseract at UB Mannheim](https://github.com/UB-Mannheim/tesseract/wiki)
- [pillow](https://pypi.org/project/pillow/#files)
