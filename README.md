# Resident-Evil-Credit-FMV-Slicer
A tool for slicing from one image into saparate images, for Resident Evil Classic credit PlayStation 1 FMV.

This tool does now supports .stf file for slicing and some supports.

# Features

This tool includes:

- Remover Backgroud option.
- Cut off. (Currently there's no need to use it)
- Support stf file, so you can slice them without any issue.
- Soft edge but with no distoration.
- Fixed Frames (Default as the old way).
- Upscale option (and it should works good).
- Skip blanks.
- Addon feature of "also save full as png" saprately.
- Full Image Only (Convert it to one PNG).
- Auto split sections.

You can later use it to manaully convert it to video.

In order to download this tool go to [release](https://github.com/mohammedtaher991/Resident-Evil-Credit-FMV-Slicer/releases) page.

Don't expect at this moment:

- Convert the FMV fully to a video, beacause staff.stf and ending.exe I haven't found a way to do so yet.
